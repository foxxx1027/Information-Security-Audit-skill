## 使用方法

1. 审计某类工作时，先读对应目录 README 中的技能清单，按链接跳到 SKILL.md 执行其 E 段步骤；
2. 技能的触发条件（A2 段）、边界（B 段）以 SKILL.md 为准——分类是导航，不是边界；
3. 未覆盖的子域见各 README 末尾『覆盖缺口』；
4. `09-通用安全方法论` 是支撑层：先查 01–08 专属技能，无匹配再回退到 09。
