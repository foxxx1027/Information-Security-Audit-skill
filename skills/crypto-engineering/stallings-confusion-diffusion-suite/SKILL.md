# 混淆-扩散检验套件

## R — 原文 (Reading)

> "仅仅在轮密钥加阶段中使用密钥。由于这个原因，该算法以轮密钥加开始，以轮密钥加结束。如果将其他不需要密钥的运算用于算法开始或结束的阶段，在不知道密钥的情况下就能计算其逆，故不能增加算法的安全性。"
>
> — 方法论出处，第6章 6.2.2 AES 的结构（首尾密钥包裹）

---

## I — 方法论骨架 (Interpretation)

自研置换/哈希/混淆函数的评审不必然要"请密码学家"——先跑一套**可自动化的黑盒回归套件**，就能证伪大多数伪安全构造。乘积密码设计有三变量（轮数×组件强度×密钥调度），每个变量各有可测指标，套件五件：

1. **影响矩阵**：逐位扰动输入，统计受影响的输出位——纯置换只搬位置不改值，"看起来乱"不构成扩散。
2. **雪崩统计**：单点扰动（明文位/密钥位）后输出汉明距离均值应≈50%且方差小。
3. **SAC/BIC（含密钥扩展）**：严格雪崩与位独立准则同样适用于子密钥序列——镜像对称的轮密钥调度，攻击者只向加密 oracle 提问一次即可解密。
4. **非线性唯一性**：找出设计中唯一的非线性步骤（AES 的 S 盒、SHA-3 的 χ），删除或线性化后重测——若仍可预测，整圈是线性方程组。
5. **首尾密钥包裹**：首尾操作若无秘密参与，其逆任何人可算，等于免费可剥离的外壳。

配套两问：逐层问"这一层单独提供什么"；轮数按"高于当前最优攻击"定余量并记录依据。

## A1 — 书中的应用 (Past Application)

### 案例 1: DES 的雪崩与 SAC/BIC 实测（第4章）
- **问题**: 怎么用数据而不是直觉说明 DES 的扩散强度？
- **方法论的使用**: 雪崩实测——明文/密钥各改一位，画出密文变化位数随轮数的收敛曲线；SAC/BIC 逐位检验；密钥扩展按同一标准审查。
- **结论**: 雪崩效应在若干轮后收敛到每位密文变化概率≈0.5，成为设计有效性的量化证据。
- **结果**: 该测试法成为教材检验分组密码性质的标准实验。

### 案例 2: AES 四层贡献与首尾包裹（第6章）
- **问题**: 四个阶段（SubBytes/ShiftRows/MixColumns/AddRoundKey）各自必要吗？为什么首尾都是轮密钥加？
- **方法论的使用**: 逐层问"单独提供什么"——轮密钥加单独使用等价于 Vernam 可破；无钥外壳反例证明首尾必须由密钥混合包住。
- **结论**: AddRoundKey 以开始与结束的姿态把整个结构包进密钥边界。
- **结果**: "这一层单独提供什么+首尾密钥包裹"成为结构审查的固定问题。

### 案例 3: SHA-3 步骤分工（第11章）
- **问题**: 海绵函数的每一步（θ/ρ/π/χ/ι）各承担什么？
- **方法论的使用**: 同一检验跨对象迁移——θ 负责扩散（影响 11 位依赖）、χ 是唯一非线性（缺失则整圈线性）、ι 破坏对称性。
- **结论**: 步骤分工可被逐项指标刻画，混淆-扩散检验不限于分组密码。
- **结果**: 套件覆盖 Hash 对象，成为跨原语的检验方法论。

## E — 可执行步骤 (Execution)

1. **跑影响矩阵**：对每个输入位扰动一次，统计受影响输出位数分布——只影响局部即伪扩散（纯置换）。
   - 完成标准: 矩阵与分布图成文。
2. **跑雪崩统计**：随机选取明文/密钥做单点扰动，输出汉明距离均值应≈50%、方差小；不达标注记失败层。
   - 完成标准: 统计报告（样本数、均值、方差）成文。
3. **查非线性唯一性**：定位唯一非线性步骤，做删除/线性化变体重测——若输出仍可预测则整圈线性。
   - 完成标准: 唯一非线性步骤被识别并验证不可省。
4. **查首尾密钥包裹**：结构审查首尾操作是否含秘密——无钥外壳标记为可免费剥离。
   - 完成标准: 首尾操作判定成文。
   - 判停条件: 标准算法（AES/SHA 族）不适用本套件（已有公开分析），直接引用。
5. **密钥扩展纳入 SAC/BIC**：子密钥序列按雪崩/位独立准则检验，镜像调度做一次 oracle 提问测试。
   - 完成标准: 密钥调度指标合格或有失败记录。
6. **出结论与余量记录**：任一项不达标即打回；全通过也注明"过滤通过≠可部署，仍需公开分析"，轮数余量记录依据。
   - 完成标准: 结论=可证伪的测试报告，非"看起来随机"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把套件通过当安全证明——它是证伪大多数自研混淆的过滤器，通过只代表获得了被认真分析的资格。
- 对标准算法重跑套件当评审——AES/SHA 已有公开分析，重复测试不产生新信息。

### 作者在书中警告的失败模式

- 无钥外壳不增加安全性（R 段原文）。
- 镜像轮密钥调度一次 oracle 提问即破（ce005）——密钥调度不是二等公民。

### 作者的盲点 / 时代局限

- 书中指标取自 DES/AES/SHA-3 的设计分析（成书 2017 前）；ARX 构造、白盒密码、掩码实现需扩充指标；统计检验不能替代差分/线性密码分析——书内的分析章节仍是最终裁判。

### 容易混淆的邻近方法论

- v53 透明准入（组织层前置）。
- v19 无钥变形测试、v07 统计残留阶数（同族不同指标）。
