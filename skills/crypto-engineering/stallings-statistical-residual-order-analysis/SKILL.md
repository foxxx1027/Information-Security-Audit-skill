# 统计残留的阶数分析

## R — 原文 (Reading)

> "如果密文行是26个字母的任意置换，那么就有26！或大于4×1026种可能的密钥，这比DES的密钥空间要大10个数量级，好像可以抵挡穷举攻击了。"
>
> — 方法论出处，第3章 3.2.2 单表代替密码（source.txt 行4072–4073；"4×1026"为 OCR 噪声，即 4×10^26）

---

## I — 方法论骨架 (Interpretation)

评估一个加密/混淆方案时，密钥空间只封住"穷举"这一条路；另一条路是**密文里残留了多少明文结构**。把残留按"阶"来数：

- 一阶：单元素频率（哪个符号最常出现）。
- 二阶及以上：元素组合的频率（双字母、n-gram）、重复序列、周期性。

单表代替 26! 个密钥仍被一阶频率分析击穿——因为一阶结构全保留。同音词替代把一阶抹平（连 Gauss 都误判牢不可破），但每个明文元素仍只影响一个密文元素，二阶模式原样残留——修补一个统计量只是把攻击推到下一阶。Playfair 把单元从 1 字母扩到 2 字母，只是把所需样本量抬高一个量级（"几百个字母的密文就足够"）。Vigenère 的周期密钥则被另一种结构残留出卖：重复明文片段相距密钥长度整数倍时密文重复，间距的公因子暴露周期。

工程验收口径由此改写：不看"人眼是否看不出规律"，而问两件事——**这个方案保留到第几阶统计结构？攻击者需要多少密文样本才能利用它？**（如要求 ≥2^40 样本才可达攻击门槛）。小分组/小状态空间等价单表代替，按此直接估成本。

## A1 — 书中的应用 (Past Application)

### 案例 1: 单表代替 26! 败于一阶频率分析
- **问题**: 密钥空间 26!≈4×10^26 比 DES 大 10 个数量级，看似穷举免疫。
- **方法论的使用**: 按"保留几阶结构"分析：单表代替一阶频率全保留，P/Z 对应 e/t 的推断 → 双字母 ZW→th → 三字母 ZWP→the 逐步消歧。
- **结论**: 穷举代价与结构泄露是两个独立指标，密钥空间只管前者。
- **结果**: 完全不碰密钥空间即可逐字母还原明文——密钥空间指标被旁路。

### 案例 2: 同音词替代的"高一阶残留"（Gauss 误判）
- **问题**: 高频字母多符号化后单字母频率被抹平，Gauss 判断其牢不可破。
- **方法论的使用**: 检查映射粒度：每个明文元素仍只影响一个密文元素，二阶（双字母音节）模式残留。
- **结论**: 只修补单一统计量=把攻击推到更高阶，结构性缺陷（一一对应）未变。
- **结果**: 组合频率分析继续破译——"修补哪一阶"成为验收问句。

### 案例 3: Vigenère 周期被重复序列间距出卖
- **问题**: 多表代替拉平了单字母频率，短密文下确实难办。
- **方法论的使用**: 换一阶结构之外的结构残留检查：相同明文序列相距密钥长度整数倍→密文重复；统计重复序列间距取公因子得周期。
- **结论**: 周期性本身就是统计入口，定长后密码退化为 m 个单表逐列击破。
- **结果**: Kasiski 法把"多表"还原成"多个单表"——周期性密钥流一律视为可被自相关分析。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评审 8 位 MCU 上的自研白盒混淆/字节替换表方案，需要定量验收标准。
2. 有人提交"自研加密/编码"（移位、查表、异或组合），宣传"密钥 128 位、看不出规律"，需要第一道评估。
3. 评估某种脱敏/假名化方案的统计可重识别性（等价类大小、组合残留）。
4. 需要为混淆方案定"攻击者需多少样本"的验收指标而非主观判断。

### 语言信号 (用户的话里出现这些就应激活)

- "自研加密/白盒混淆怎么验收"
- "密钥空间够大就安全吧"
- "frequency analysis / 统计结构 / n-gram"
- "看不出规律，应该安全"
- "需要多少密文/样本才能破"

### 与相邻 skill 的区分

- 与 `stallings-linearity-solvability-test` 的区别: 线性检验针对代数结构（已知明文解方程，一击致命）；本 skill 针对统计结构（需要样本量的渐近攻击）。自研方案两道闸都要过：先线性度、后统计阶。
- 与 `stallings-analysis-cost-vs-brute-force`（理想原语判据）的区别: 那个评标准算法（有没有比穷举快的公开分析）；本 skill 评非标准/自研变换（保留几阶结构、需多少样本）。
- 与 `stallings-brute-force-three-conditions` 的区别: 那个管穷举这条路成不成立；本 skill 管穷举之外的分析路——两条路一起构成双指标。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定结构单元**: 写出方案的加密/混淆粒度（单字节？块？流？），并确定映射是"一单元→一单元"还是跨单元扩散。
   - 完成标准: 有一句话结论"输入单元与输出单元是否一一对应"。
   - 判停条件: 若发现周期性密钥/种子复用（任何形式的固定周期），直接判"存在周期入口"，进入第 4 步换构造，无需继续数阶。
2. **数残留阶**: 逐阶列出保留的统计量——一阶频率、二阶组合、重复序列、周期。
   - 完成标准: 每阶标注"已抹平/残留"，附直观理由。
3. **估算样本量**: 对每个残留阶估攻击者利用它所需的密文/数据量（量级即可）。
   - 完成标准: 输出"攻击门槛 ≈ 2^k 样本"的量级结论，并写明依据。
4. **定档与改造**: 若样本门槛低于资产价值对应的档位（如 <2^40），要求跨单元扩散+非线性+多轮复合；小状态空间方案直接按单表代替估成本并退回。
   - 完成标准: 给出"通过/退回/需改造"结论与改造方向。
5. **写验收指标**: 把"攻击者需 ≥2^k 样本"写进方案验收条款，替代"看不出规律"。
   - 完成标准: 验收条款可测试（能构造对应的统计测试用例）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 标准算法（AES、ChaCha 等）的强度评估——它们的统计与代数性质已经过公开分析定标，用"分析代价≥穷举"判据即可。
- 实现层侧信道（时序、功耗、故障注入）——那是另一族分析方法，本书在第9章计时攻击处另行处理。
- 数据量极小的一次性场景（样本永远不够）——分析门槛天然成立，重点转回密钥管理与协议。

### 作者在书中警告的失败模式

- 以密钥空间为唯一指标（单表 26! 的教训）。
- 修补单一统计量就宣布封死分析（Gauss 同音词误判）。
- 把"增大单元"当质变（Playfair 只抬样本量一个量级，仍是量变）。

### 作者的盲点 / 时代局限

- 书中递进案例全部来自古典密码；对现代语境（机器学习辅助的统计区分、差分隐私场景下的重识别）未涉及，样本量估算需按现代攻击者能力修正。
- "多少样本"在书中多为叙述性数字（"几百个字母"），未给系统的样本复杂度计算方法。
- 第7版成书于 2017 前后，白盒密码学的正式分析方法书中未覆盖。

### 容易混淆的邻近方法论

- 与熵评估（信息论）: 熵度量不确定性上界；阶数分析度量**可利用结构**——高熵输出仍可能带可利用组合残留。
- 与"扩散/混淆"设计原则: 那是构造手段；本 skill 是对构造结果的检验口径（保留几阶、多少样本）。
