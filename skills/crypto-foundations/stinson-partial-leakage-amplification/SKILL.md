# 部分信息泄漏与放大器——一位泄漏可被同态+二分放大为全恢复

## R — 原文 (Reading)

> 也就是说，一个RSA加密"泄漏"了一些有关明文的信息，即Jacobi符号的值。
>
> 也就是说，计算关于明文的特定部分信息，即half(y)，不会比解密密文得到整个明文来得容易。
>
> — 原作者,原始方法论来源第5章 5.9.1（中译本 OCR，逐字保留）

---

## I — 方法论骨架 (Interpretation)

"攻击者只拿到一个比特，无伤大雅"是对公钥加密最危险的错觉，因为比特会放大。放大器需要两个零件：一个可计算谓词（密文上多项式可算的明文属性——RSA 的 Jacobi 符号免费泄漏：b 为奇数使 (y/n)=(x/n)，无需私钥）；一个代数同态（加密函数的可组合性——e(x)·e(2)=e(2x)，倍乘密文等于倍乘明文）。两件拼起来：每次询问"明文 <n/2 吗"（half 谓词），把密文乘 e(2) 使候选区间倍乘，二分查找 log n 步把 x 唯一区间收缩到单点——一位泄漏放大成完整解密，全程 O(log n) 次查询。基本 ElGamal 的同类破绽：β、y1 的二次剩余性可公开判定（Euler 准则），判别器即区分两条候选明文——"部分攻破"真实存在。系统排查泄漏面按两轴：谓词轴——枚举密文上多项式可计算的明文谓词（二次性、区间/高位、奇偶性），任何非平凡谓词即部分泄漏；同态轴——查加密函数的代数性质（可乘/可加），若谓词能与密文运算组合，即可构造 half 型放大器。结论口径："未恢复全明文"不是安全证据，泄漏面按谓词×同态两轴清点。

## A1 — 书中的应用 (Past Application)

### 案例 1: RSA 的 Jacobi 泄漏与 half 放大器
- **问题**: RSA 泄漏"一个符号"要紧吗？
- **方法论的使用**: 第 5 章 5.9.1：gcd(b,Φ(n))=1 使 b 为奇数，任何人都可从 y 算出 (x/n)；再假设存在 half 谕示器，算法 5.13 反复乘 e(2) 得 e(x·2^i)，逐次询问区间判断，二分定位。
- **结论**: 例 5.19 中 n=1457、y=722 经 O((log n)²) 步还原 x=999——"一个比特的部分信息"若可高效计算即等价于完整解密；parity 与 half 多项式等价。
- **结果**: 语义安全定义收拢一切信息类型：密文不得泄露任何可计算函数，而非仅"不可解密"。

### 案例 2: 基本 ElGamal 被 QR 判别区分
- **问题**: "解密等价于解 CDH"能推出 ElGamal 语义安全吗？
- **方法论的使用**: 第 6 章 6.7：由 β、y1 的二次剩余性可算出 β^k 的 QR 性，结合 y2 的 QR 性判定明文属哪类——公开的 Euler 准则即区分器。
- **结论**: 存在多项式时间明文属性判别器，语义安全失败；安全假设需强于 DLP（升到 DDH 并把运算限制在 QR 子群）。
- **结果**: "部分攻破"成为必须显式排除的目标档位；子群限制是修复样板。

### 案例 3: 差分分析中的密钥消去——免密钥观测量的同源思想
- **问题**: 攻击者不知道轮密钥，如何构造可观测量？
- **方法论的使用**: 第 3 章 3.4：两次加密的异或中轮密钥 K^r 完全相消（u^r⊕u'^r=w^{r-1}⊕w'^{r-1}），差分链在不知道密钥的情况下从明文推到最后一轮之前。
- **结论**: "寻找与密钥无关的可观测量"是免密钥分析的通用杠杆——泄漏放大与密钥消去是同一思想（构造敌手可算的函数）在攻击两端的应用。
- **结果**: 排查泄漏面时同样问："什么量是敌手可计算而设计者不希望的？"

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估新公钥方案/变体（自定义编码、无填充原语）宣称"安全"，需要系统找它的泄漏面。
2. 评审同态性质的利弊：方案带代数组合性（可乘/可加）时泄漏放大的风险核算。
3. 密码分析：手头有一个针对某公钥方案的区分器/单比特预测器，评估能否放大。
4. 解释"语义安全为什么定义成不可区分"而不是"不可解密"。

### 语言信号 (用户的话里出现这些就应激活)

- "partial information / bit leakage / 只泄一个比特有关系吗"
- "Jacobi symbol / parity / half 谕示是什么"
- "homomorphic amplification / 同态放大攻击"
- "密文上能算出明文的什么性质 / 区分器 distinguisher"
- "这个方案只是被区分了，没被破解吧"

### 与相邻 skill 的区分

- 与 `stinson-simulatability-zero-knowledge` 的区别: 那个是守方论证"零泄漏"（模拟器）；本 skill 是攻方系统找泄漏（谓词×同态清点）——模拟测试失败的点，正好用本 skill 的放大器验证可利用性。
- 与 `stinson-deterministic-pke-fails` 的区别: 那个是外延枚举（加密候选比对，需要明文空间小）；本 skill 是内蕴谓词（密文上直接算明文属性，与明文空间无关）——两条独立的泄漏路，都要查。
- 与 `stinson-oracle-surface-control` 的区别: 本 skill 讲泄漏位如何被同态放大成全恢复（信息面）；那个讲能力接口如何被组合成谕示（计算面）——常配合使用。
- 与 `stinson-signature-homomorphism-breaking` 的区别: 同一同态性质攻不同目标——本 skill 是加密侧"谓词×同态放大"，那个是签名侧"同态组合伪造"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **写出加密函数的代数形态**: 输入输出的群结构、可组合运算（可乘/可加/倍乘）、填充与随机化情况。
   - 完成标准: 同态清单（有/无，何种）；裸原语与带填充版本分开列。
2. **枚举密文上可计算的明文谓词**: 二次剩余性、区间/高位信息、奇偶性、群成员性等，逐个检验是否多项式可算。
   - 完成标准: 谓词清单 + 每项"可算（泄漏成立）/不可算"判定。
   - 判停条件: 若存在非平凡可算谓词且方案有可乘/可加同态，直接输出"放大器可构造"结论跳到步骤 4。
3. **测试放大器组装**: 谓词能否与密文运算组合（倍乘/相加后谓词仍可算）；区间类谓词走二分、群成员类走子群判别的路径推演。
   - 完成标准: 放大路径（谓词×运算×迭代结构）逐步写出 + 查询次数估算。
4. **核对修复面**: 随机化填充切断可计算性；运算限制在适当子群（ElGamal 的 QR 修复样板）；破坏同态与谓词的组合性。
   - 完成标准: 每条泄漏路径附一条修复及其对功能（同态用途）的影响。
5. **输出泄漏面报告**: 谓词×同态两轴矩阵；结论口径"未恢复全明文不是安全证据"，放大成功的路径置顶。
   - 完成标准: 矩阵每格有判定；置顶路径含完整推演。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对称加密的模式泄漏（ECB 相同块相同密文）——那是确定性/模式问题，归组合检查表；本 skill 针对公钥原语的代数谓词。
- 侧信道泄漏（时间、功耗）——实现层的观测通道，不在"密文上可计算"的范畴，另线审计。
- 有意设计同态加密（FHE/隐私计算）的场景——同态是功能需求，泄漏边界由噪声/参数管理，评价框架不同。

### 作者在书中警告的失败模式

- "一个比特没关系"——half/parity 谕示被证明与完整解密同难度（第 5 章 5.9.1）。
- 把"解密等价于难题"当语义安全——ElGamal 的 QR 区分器是反例（第 6 章 6.7）。
- 半区归约被过度解读：证明未排除 75% 准确率的单比特算法——量化范围是证明边界的一部分。

### 作者的盲点 / 时代局限

- 成书 2006 年：格基后量子方案的泄漏谓词（LWE 误差分布的可察觉偏差）、对特定编码（如重复填充）的高低位攻击未覆盖；谓词枚举的思路可迁移，具体谓词族需按现代方案扩展。
- 自适应攻击（chiperhext malleability 链）与 CCA 的系统关系（Naor-Yung 双重加密等）超出本书范围。

### 容易混淆的邻近方法论

- 泄漏放大 ≠ 密文延展性（malleability）：延展性指"改密文得相关明文"（完整性问题）；泄漏放大指"读密文算明文属性"（机密性问题）——同态性两个方向都能吃，审计目标不同。
- 与谕示面收敛的区别：那边管"接口发放计算能力"；本 skill 管"密文本身内蕴的信息"——一个砍接口，一个清字段。
