# 面谈提问纪律（八注意：请对方描述开场、避免引导性提问、结尾总结评审）

## R — 原文 (Reading)

> "（5）面谈可通过请对方描述其工作开始；
> （6）应当避免提出有倾向性答案的问题（如引导性提问）；
> (7) J 应当与对方总结和评审面谈的结果；
> （8）应当感谢对方的参与和合作。"
>
> — 原作者、原作者，原始方法论来源第4章 4.2.2 现场调查·面谈注意（source.txt L2788–2794，OCR"(7) J"杂字原样保留）

## I — 方法论骨架 (Interpretation)

一场取证访谈的产出是**证据**，所以访谈本身要有证据保全意识。八条纪律各管一段：

1. **对象与环境**（1–3 条）：找对层次与职能的人、在正常工作时间地点谈、先让对方放松——防御性回答是取证噪声。
2. **程序透明**（4 条）：解释为什么谈、为什么记录——被暗访感会催生表演性回答。
3. **开场范式**（5 条）：以"请描述你的工作"开始——开放式描述让流程自己暴露，是非题留给确认环节。
4. **问法红线**（6 条）："你们是不是每天都检查日志？"这类引导性问题**必然**收获"是"——它制造的是虚假符合，比没有证据更糟。
5. **结尾闭环**（7–8 条）：复述听到的流程、请对方纠正——对方当场说出的"其实例外的时候我们不记"是高价值线索。

纪律是可回查的：访谈记录被申诉时，逐条对照八注意找程序瑕疵。

## A1 — 书中的应用 (Past Application)

### 案例 1: 面谈八注意作为现场固定程序（4.2.2，cs21）
- **问题**: 现场访谈随意化，取到的"符合"陈述不可靠。
- **方法论的使用**: 作者把 ISO19011 面谈规程落成 8 条可执行注意，编排进现场调查的标准动作（信息源 14 类之后紧接面谈规程），与其构成"收集什么+怎么收集"的配套。
- **结论**: 访谈是程序化取证动作，不是聊天；程序瑕疵可回查。
- **结果**: 该规程成为现场审核的固定节，访谈记录质量纠纷时按八条逐项核查。

### 案例 2: 跨章重申（3.4.4 审核策略和技巧）
- **问题**: 面谈纪律是第4章的局部要求还是通用技巧？
- **方法论的使用**: "避免引导性提问"与"面谈后总结评审结果"在第3章 3.4.4 审核技巧节再次出现——同一纪律跨章复用。
- **结论**: 提问纪律是审核员的基本功，不随场景失效。
- **结果**: 与检查表"不限制审核内容"（开放收集）共同构成审核技巧层的方法对。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 远程视频访谈一线运维/值班人员：对方带摄像头紧张、习惯性顺着说"是"。
2. 内审访谈业务部门负责人，核对其职责条款的实际履行方式。
3. 事故调查/事件复盘找当事人还原流程，担心问法诱导出"理想版流程"。
4. 供应商现场审计访谈其 SOC/客服，验证 SLA 承诺的真实执行。

### 语言信号 (用户的话里出现这些就应激活)

- "访谈总是得到'是的是的'，怎么问才真实？" / "interviewees just agree with everything"
- "怎么问才不算引导性问题？" / "leading question examples"
- "访谈结尾要不要复述确认？" / "summarize and verify at the end"
- "对方很紧张，顺着我说怎么办？"
- "让他演示还是口头确认？"（演示优于口头确认——开放式取证据）

### 与相邻 skill 的区分

- 与 `isms-interview-tiering`：那是访谈前的选档设计（找谁、谈到什么深度）；本 skill 是访谈现场的单场纪律。组合顺序：先 tiering 定档定人，进现场后用本 skill 执行。
- 与 `isms-evidence-admissibility-threshold`：本 skill 采到的口头陈述在交叉证实前只是线索——"其实例外时不记"这类纠正性陈述按证据门槛处理，不得直接开不符合。
- 与教练式提问/5 Why 引导：那些是改进与辅导工具，鼓励引导思考；取证访谈目的相反——引导即污染。

## E — 可执行步骤 (Execution)

1. **访前检查对象与环境**：确认对象来自审核范围内实施该活动的适当层次与职能，约定正常工作时间（可行时正常地点）。
   - 完成标准: 对象-职能匹配表；时间地点符合"正常"判据。
2. **开场三动作**：解释面谈与作记录的原因 → 使对方放松 → 请对方描述其工作（禁以是非题开场）。
   - 完成标准: 访谈记录首段含对方的工作描述，而非问答勾选。
3. **提问自查**：逐题检查是否含预期答案（"是不是/对吧/应该有吧/每天都吧"句式一律禁止），改写为"描述/展示/举例/走一遍"式。
   - 完成标准: 问题清单零引导句式；每题可归入开放/确认两类并标注。
4. **取证实操**：能演示的不口头确认（请对方屏幕演示/调出记录），口头陈述标注为待证实线索。
   - 完成标准: 关键事实至少有一个非口头载体（截图、记录、演示）。
5. **结尾总结评审**：复述听到的关键流程请对方纠正，记录纠正内容并致谢。
   - 完成标准: 记录含"复述→确认/纠正"段；纠正出的例外陈述转入证据门槛流程（线索池）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 渗透测试中的社会工程学模拟——那是蓄意诱导，纪律目标相反。
- 绩效面谈、咨询辅导等管理沟通——无取证义务，不适用本程序。
- 匿名问卷/举报渠道取证——非面谈形态，程序要求不同。

### 作者在书中警告的失败模式

- ce29：引导性提问（带倾向性答案的问题）取证——证据独立性被问法本身破坏，"基于证据的方法"名存实亡。
- 对象错层：只与高层谈一线执行细节、或只与一线谈管理决策——第 1 条注意即被违反，取到的是转述而非事实。

### 作者的盲点 / 时代局限

- **版本提示**：八注意源自 GB/T19011—2003/ISO19011:2002；现行 19011:2018 已补充远程审核方法（视频访谈的录制、记录与同意要求），远程场景须在八注意之上叠加现行指南，书中无此维度。
- 书中无访谈失败实测案例与对照数据，八条为程序性规范；对"如何分辨表演性回答"只有结尾总结评审一道防线。
- 2012 年成书，未涉及跨语言/跨文化访谈的引导性偏移问题。

### 容易混淆的邻近方法论

- 认知访谈法（cognitive interview，证人取证技术）：更细的同族技术（情境还原、开放式多轮）；本 skill 是其审核场景的最小规程。
- 记者采访技巧：形态相似但目的是信息获取而非可复核证据，无记录与评审闭环要求。
