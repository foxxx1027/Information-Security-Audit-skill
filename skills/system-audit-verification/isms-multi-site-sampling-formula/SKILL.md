# 多场所抽样计算（相似性闸门、平方根×风险系数、总部必查）

## R — 原文 (Reading)

> "b）多现场抽样原则：具有相似性的现场可以抽样；不具相似性的现场不能抽样，必须进行审核。c）抽样量（每次审核至少必须覆盖的场所数量）：低信息安全风险行业的样本量≥（为分场所数量的平方根，下同），上人成整数;高信息安全风险行业的样本量y≥1.4√z，上入成整数；"
>
> — 原作者、原作者，原始方法论来源第3章 3.5.5 初审/第二阶段（source.txt L2377–2382，OCR"上人成整数/上入成整数"="向上取整"原样保留）

## I — 方法论骨架 (Interpretation)

多场所审核"抽几家"不是拍脑袋，是一套闸门+公式+硬规则：

1. **相似性闸门（先于一切计算）**：具有相似性的现场可以抽样；不具相似性的现场**不能抽样、必须全查**。相似性要论证（职能/流程/风险画像相近），且论证要留痕——它承接着"抽样的合理性与审核结论的可信性密切相关"的总纲。
2. **平方根×风险系数**：最低样本量按分场所数量平方根乘风险系数，向上取整——初审/二阶段：低风险 ≥√z、高风险 ≥1.4√z；监督审核：0.6√n（低）/0.9√n（高）；再认证运行良好可降至 0.8√n/1.1√n。抽样方案由审核组长按风险定，优先抽风险大的分现场。
3. **总部必查**：总部（管理控制平面）每次审核必查，**不可抽样**；证书有效期内还须实现全部场所覆盖 + 每次必查部门清单。

三条的内在逻辑：相似性是抽样的**准入前提**（不相似则样本无代表性可言），系数只调节相似前提下的量，而总部承载策略与记录，抽掉它整个体系证据就断了根。

**重要限定**：系数是认证行业惯例转写，书内无统计推导——使用时注明来源并按组织风险自行校准。

## A1 — 书中的应用 (Past Application)

### 案例 1: 初审抽样系数（3.5.5）
- **问题**: 首次发证审多少家分现场？
- **方法论的使用**: 相似性判定 → 低风险 ≥√z、高风险 ≥1.4√z 向上取整，优先风险大的分现场。
- **结论**: 抽样量可复算、留底稿。
- **结果**: 作为二阶段计划的编制输入（案例引用 cs11）。

### 案例 2: 监审/再认证阶梯（3.5.6–3.5.7）
- **问题**: 发证后的三年周期内抽样怎么变？
- **方法论的使用**: 监审 0.6√n/0.9√n；再认证运行良好降至 0.8√n/1.1√n；总部每次必查；证书有效期内全覆盖 + 每次必查部门清单（管理者代表、策划部门、机房、网络岗位等）。
- **结论**: 三年完整抽样阶梯，覆盖义务与抽样优惠并行。
- **结果**: 监审计划可直接套用系数并核对必查清单（cs12）。

### 案例 3: 不相似零豁免（3.5.5 + ce24）
- **问题**: 统一按比例抽 30% 行不行？
- **方法论的使用**: 硬边界——不相似现场不能抽样必须全查；另原则上不超过 3 个抽样场所、每场所至少 1 天。
- **结论**: 比例抽样不做相似性判断即审核策划缺陷。
- **结果**: ce24 将其定性为"抽样方法的红线条款"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 连锁/集团（几十上百家门店或分支）内审或认证审核的年度抽样方案设计。
2. SaaS 公司多 cloud region（4 个 region + 30 家远程办公点）部署的安全审核抽样。
3. 被质疑"凭什么只抽这几家"，需要书面抽样依据与计算底稿。
4. 制定多年审核规划（初审→监审→再认证）的覆盖节奏。
5. 加盟/直营混合业态：哪些现场必须全查的判定。

### 语言信号 (用户的话里出现这些就应激活)

- "200 家门店审几家的依据是什么？" / "how many sites to sample"
- "多场所抽样怎么算？" / "multi-site sampling formula"
- "所有分部都差不多，能不能只抽几家？"（先过相似性闸门）
- "总部/管理中心每次都要去吗？"（必查不可抽样）
- "√ 公式 / square root sampling rule 是哪来的？"（认证惯例，需自行校准）

### 与相邻 skill 的区分

- 与 `isms-sampling-uncertainty-disclosure`：本 skill 定"抽多少/抽谁"；披露 skill 定"抽完后结论怎么说"。一次完整策划两者都要。
- 与 `isms-two-stage-audit-gate`：两阶段门禁管"何时进现场"；本 skill 管"进场后覆盖哪些场所"。一阶段定抽样方案是两阶段的衔接点。
- 与一般统计抽样：本方法是行业惯例非概率抽样设计，不产生统计置信度，别拿置信区间话术包装。

## E — 可执行步骤 (Execution)

1. **场所清单与画像**：列出全部场所，标注业务职能、部署架构（IaC 模板/管理平面归属）、法域与风险等级。
   - 完成标准: 场所总表（z 值确定）+ 每场一行画像。
2. **相似性闸门判定**：逐场论证相似性（同架构同控制平面→相似；独立法域/独立研发中心等→不相似）；不相似现场单列。
   - 完成标准: 相似/不相似两栏清单 + 论证理由；不相似者全部纳入必查。
   - 判停条件: 若不相似场所数已超出资源承受 → 不是扩大抽样而是重新协商范围/分期，不得静默放弃必查。
3. **计算样本量**：对相似集合按阶段选系数（初审 1.4√/√、监审 0.9√/0.6√、再认证 1.1√/0.8√）计算并向上取整；注明系数来源与校准说明。
   - 完成标准: 计算底稿（公式、z、系数、结果）+ 风险优先排序（先抽风险大的）。
4. **锁定必查项**：总部/管理平面（含云管理账号）必查；必查部门清单列入计划。
   - 完成标准: 计划中"必查（不可抽样）"栏非空且覆盖管理控制平面。
5. **周期覆盖规划**：核对证书/审核周期内全场所覆盖路径与历次必查记录。
   - 完成标准: 覆盖矩阵（场所×年度）无永久漏项；方案交 isms-sampling-uncertainty-disclosure 做披露。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 单场所组织——无多场所问题，抽样只涉及记录/人员层面。
- 需要统计置信度的调查（用户研究、质检 AQL）——本方法不提供统计保证。
- 场所高度异质（每家业务都不同）——闸门判完大多必查，公式基本用不上，别硬套。

### 作者在书中警告的失败模式

- ce24：对不具相似性的多现场做抽样——"不具相似性的现场不能抽样，必须进行审核"；按统一比例抽、不做相似性判断即策划缺陷。
- ce23：把抽样结论当全量结论——抽样合理性系于结论可信性，方案不留痕则结论无根。

### 作者的盲点 / 时代局限

- **系数是黑箱（重点）**：1.4√/0.9√/0.6√/0.8√/1.1√ 为认证行业惯例转写，书内无统计依据或出处（verified.md 口径说明 5、BOOK_OVERVIEW 未证明假设）——使用时必须注明"系数源自认证惯例、无书内统计推导，须按风险自行校准"。
- **版本与时代提示**：系数体系出自 2012 年前认证机构实践（对标 CNAS/IAF MD1 类规则），现行 IAF MD1:2022 多场所抽样规则已有调整（中央职能、场所选择准则更细化）；云 region、远程办公点是 2012 年不存在的形式，需按"管理平面必查 + 部署相似性"逻辑映射（verified.md V2 已外推验证）。
- 书中"不超过 3 个抽样场所、每场所至少 1 天"等附则同样为惯例，无推导。

### 容易混淆的邻近方法论

- 统计抽样（分层/整群抽样）：有概率论基础；本方法是惯例公式，逻辑是"相似性授权抽样+总部例外"，不要混用术语。
- 审核人日数估算：总时间预算问题（书中另有九因素清单，同为惯例转写），与场所数抽样量是两个变量。
